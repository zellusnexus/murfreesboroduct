# Murfreesboro Duct Cleaning

Static website for Murfreesboro Duct Cleaning — 925 S Church St, Murfreesboro, TN 37130 · (615) 857-5923.

## Editing pages

Page content lives in `_src/pages/` as HTML fragments with a small front-matter block
(title, meta description, URL path, H1, breadcrumbs, etc.). The shared header, nav,
footer, breadcrumbs, JSON-LD schema and `sitemap.xml` are generated by the build script.

After editing anything in `_src/`, rebuild:

```bash
python3 _src/build.py
```

Then commit both the `_src/` change and the regenerated HTML. Nav, footer, service and
service-area lists are defined at the top of `_src/build.py`.

## Site structure

- `/` – home (Murfreesboro)
- `/services/` + 6 service pages
- `/service-areas/` + 9 city pages (`/service-areas/<city>-tn/`)
- `/air-duct-cleaning-cost/` – pricing guide
- `/resources/` + 3 homeowner guides
- `/faq/`, `/about/`, `/contact/`, `404.html`
- `sitemap.xml`, `robots.txt`, `og-image.png`, `favicon.svg`

Deploy the repo root to any static host (Netlify, GitHub Pages, Cloudflare Pages).
After launch, submit `https://murfreesboroductcleaning.com/sitemap.xml` in Google Search Console.
